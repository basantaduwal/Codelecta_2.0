# Codelecta

### A Web-Based Interactive Programming Learning Platform

Codelecta is a web-based programming learning platform designed to provide structured and practical programming education for beginners, university students, and working professionals.

The platform aims to provide programming lessons, practical examples, quizzes, and learning progress in a single learning environment.

---

## Project Overview

Codelecta will allow learners to:

- Create an account and log in
- Explore programming courses
- Access structured programming lessons
- View practical code examples
- Watch learning videos
- Complete interactive quizzes
- Track their learning progress
- View their learning activity
- View leaderboard rankings
- Receive course recommendations

Administrators will be able to manage:

- Users
- Courses
- Lessons
- Quizzes
- Questions
- Learning content
